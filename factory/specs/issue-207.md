## Design / approach

Keep the site renderer a pure, deterministic, offline transform (stdlib + PyYAML, all text html.escape-d, no JS, no external assets). Restructure only the top of `architecture_html()`: add the static newcomer content (pitch, SVG diagram, human-decides box, depth links) as Python string parts, and change the loop rendering from the raw `<ol>` of `numbered_steps()` to a card list — parse the `## Loop` numbered steps, strip inline markdown markers (`**` and backticks) before escaping, and split each step into a title and description so the literal `**` disappears. Leave the existing Roles / Merge authority / Models and prices / Routing rules / Guard checks table structure in place so the tested contract (especially test 3's routing-rules table) keeps passing, while stripping `**` and backticks from any FACTORY.md-derived cell text. Add the depth links as repo-relative hrefs so they satisfy test 9's link allowlist. Add the new `<svg` + no-`**` check as an additional test in `scripts/test-factory-site.sh` using the same offline fixture-render path the existing tests use.

## Alternatives considered

Not required for standard/normal, but briefly: fully removing the reference tables and pushing all depth into the docs was considered and rejected because it would break the existing test 3 (routing-rules table) and the issue does not ask to remove them — the newcomer content is added at the top while the tables stay as the at-a-glance reference. Pulling the loop diagram from FACTORY.md text was considered and rejected in favor of a static inline SVG, because the diagram's stage list (ideas → triage → ... → feedback) differs from the numbered FACTORY.md loop steps, and a static SVG is deterministic, offline and repo-agnostic.

## Risks, rollback and revert trigger

Risk: the redesign could accidentally drop or reorder one of the existing reference tables, breaking test 3 or other existing site tests. Mitigation: keep those table renderers unchanged and run the full `bash scripts/test-factory-site.sh` (the verification harness runs it) which fails loudly if a table is missing. Risk: the SVG or cards could break the byte-identical-determinism check (test 7). Mitigation: build the SVG and cards from static strings / deterministic parsing with no wall clock or randomness; the existing pinned-build-time test verifies this. Risk: a depth link or the pitch could regress test 9's link allowlist. Mitigation: use repo-relative hrefs and plain text, verified by test 9. Rollback is a normal code revert of `scripts/factory-site.py`, `scripts/test-factory-site.sh` and `factory/site/README.md`. Revert trigger: if the updated test suite shows a reference table missing, a literal `**` reappearing, a non-deterministic render, or a forbidden external link, revert.
